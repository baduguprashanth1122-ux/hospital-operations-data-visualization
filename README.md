# Hospital Operations & Patient Outcomes — Data Visualization Project

A 6-week end-to-end Healthcare Data Visualization project focused on solving hospital operational bottlenecks—specifically **Emergency Department (ED) wait times, inpatient bed occupancy, 30-day readmission rates, and treatment costs**.

## Tools & Tech Stack
* **Data Cleaning & Querying:** SQL, Microsoft Excel
* **Visualization & Dashboards:** Power BI
* **Documentation:** Strategic Planning, Wireframing, and Executive Reporting

## Repository Structure
* `Week-1-Strategic-Plan/` — Strategic plan, KPI framework, stakeholder analysis, and risk mitigation.
* `Week-2-Dashboard-Prototype/` — Dashboard wireframes, chart selection rationale, and layout hierarchy.
* `Week-3-Data-Workflow/` — Data sourcing, SQL/Excel cleaning scripts, and ETL workflow diagrams.
* `Week-4-Interactive-Visuals/` — Interactive dashboard mockups, dynamic filters, and drill-down flows.
* `Week-5-Impact-Optimization/` — Evaluation framework, usability KPIs, and optimization strategies.
* `Week-6-Final-Executive-Report/` — Integrated executive report and final recommendations.

## Core KPIs Tracked
1. **Triage-to-Doctor Time** (Protecting the clinical "Golden Hour")
2. **Decision-to-Admit to Ward Transfer Time** (Reducing ED boarding)
3. **Bed Occupancy Rate (%) & Bed Turnaround Time (TAT)**
4. **30-Day Readmission Rate** (Sliced by Department & Payer Type)
5. **Average Treatment Cost per Case**
